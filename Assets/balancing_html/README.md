# Habemus Papam Balancing Simulator

Unity 원본 프로젝트 `habemus-papam`을 직접 수정하지 않고, 기획자가 수동 플레이와 밸런스 확인을 할 수 있도록 만든 별도 시뮬레이터입니다.

## 현재 범위

- 수동 플레이 모드
- 플레이어 1명 + NPC 3명
- 능력치 0~10 정수화
- 썬클라베 기본 4턴
- 각 턴 행동 2회 + 이벤트 1회
- 초기 능력치 조정
- x턴마다 체력 y 감소 설정

## 실행

`index.html`을 브라우저에서 열면 됩니다.

## 기획 우선순위

- `docs/작업_권한_및_범위.md`를 가장 먼저 따른다.
- 채팅으로 추가된 기획은 `docs/추가기획.md`에 기록한다.
- 구현 판단이 충돌하면 `docs/추가기획.md`를 `habemus-papam` 게임 파일보다 우선한다.
