# 작업 권한 및 범위

## 최우선 규칙

이 작업을 시작하거나 이어서 진행할 때는 항상 이 문서를 가장 먼저 확인한다.

## 작업 대상

- 실제 구현, 생성, 수정 작업은 현 `balancing_html` 폴더에서만 수행한다.
- 밸런싱 프로그램은 Unity 게임 `habemus-papam`을 참고해 별도 프로그램으로 만든다.
- 새 파일, 설정 파일, 빌드 산출물, 임시 산출물은 `balancing_html` 폴더 안에만 둔다.

## 참고 전용 경로

- `C:\Users\user\Documents\GitHub\habemus-papam`

위 폴더는 Unity 게임 원본 프로젝트로, 내부 스크립트와 데이터 구조를 이해하기 위한 참고 전용이다.

## 금지 사항

- `balancing_html` 폴더 외부에 별도 지시가 없지 않은 이상 새 파일을 만들지 않는다.
- `balancing_html` 폴더 외부에 별도 지시가 없지 않은 이상 기존 파일을 수정, 삭제, 이동, 포맷팅하지 않는다.
- `balancing_html` 폴더 외부 프로젝트에 패키지 설치, 빌드, 생성 코드 출력, 캐시 생성 작업을 수행하지 않는다.
- 참고 과정에서 필요한 메모나 분석 결과도 `balancing_html` 내부에만 기록한다.

## 허용 사항

- `habemus-papam` 폴더의 스크립트, ScriptableObject 정의, 데이터 구조, enum, 밸런스 관련 로직을 읽고 분석한다.
- 분석 결과를 바탕으로 `balancing_html` 폴더 안에 별도 도구, 문서, 테스트, 데이터 변환 코드를 작성한다.
- 원본 프로젝트와의 차이를 명확히 하기 위해 `balancing_html` 내부 문서에 참고한 파일 경로와 해석을 기록한다.

## 작업 전 체크리스트

1. 이 문서를 먼저 읽었는지 확인한다.
2. 현재 쓰기 대상이 `balancing_html` 내부인지 확인한다.
3. 그 외 경로는 읽기 전용 참고 대상으로만 사용한다.
4. 파일 생성이나 수정이 필요하면 대상 경로가 `balancing_html` 내부인지 확인한 뒤 진행한다.

## 운영 메모

이 문서는 이 프로젝트의 작업 경계와 권한 규칙을 정의한다. 이후 Codex 작업에서는 이 문서를 우선 컨텍스트로 삼고, 불명확한 경우 `habemus-papam`을 보호하는 방향으로 판단한다.
