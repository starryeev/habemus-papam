# 추가기획

이 문서는 채팅을 통해 추가로 주어진 기획사항을 저장하는 문서다.
구현 시 `habemus-papam` Unity 게임 파일보다 `핵심-기획.txt`와 이 문서의 내용을 우선한다.

## 우선순위 규칙

1. `작업_권한_및_범위.md`의 작업 경계와 권한 규칙을 최우선으로 따른다.
2. 게임 규칙이나 밸런스 해석이 충돌할 경우, `핵심-기획.txt`와 본 `추가기획.md`를 `habemus-papam` 게임 파일보다 우선한다.
3. `habemus-papam`은 기존 구조와 명칭을 이해하기 위한 참고 자료로만 사용한다.
4. 새 기획이 채팅으로 주어지면 이 문서에 먼저 기록한 뒤 구현에 반영한다.

## 2026-07-07 수동 플레이 모드 1차 기획

- 기획자가 게임을 직접 플레이할 수 있는 수동 플레이 모드부터 구현한다.
- 기존 게임 내 자유행동은 시뮬레이터에서 턴제 행동으로 바꾼다.
- 능력치는 기존 0~100 float이 아니라 0~10 int로 표현한다.
- 각 썬클라베는 조작 가능한 턴으로 구성된다.
- 조작 가능 턴 기본값은 4턴이다.
- 각 턴에서는 행동 2번과 이벤트 1번이 발생한다.
- 초기 플레이어 1명 및 NPC 3명의 능력치 조건을 조절할 수 있어야 한다.
- x턴마다 체력이 y만큼 감소할 때의 x, y 값을 조절할 수 있어야 한다.

## 현재 구현 범위

- 브라우저에서 바로 열 수 있는 정적 웹 수동 플레이 시뮬레이터를 만든다.
- 설정 패널에서 썬클라베 턴 수, 체력 감소 주기, 감소량, 후보별 초기 능력치를 조절한다.
- 플레이 중 후보별 능력치는 0~10 정수 범위로 고정한다.
- 한 턴은 행동 2회 후 이벤트 1회 순서로 진행된다.
- 이벤트 처리 후 설정된 주기에 따라 전체 후보 체력 감소를 적용한다.

## 2026-07-07 이벤트 및 공작 수정

- 공작은 능력치가 아니라 행동이다.
- 후보 능력치는 체력, 경건, 정치 3종으로 정리한다.
- 이벤트는 `docs/이벤트.csv`를 기준으로 구현한다.
- 원본 이벤트 수치가 0~100 능력치 기준이므로 시뮬레이터에서는 1/10로 축소해 적용한다.
  - 예: `체력 +20`은 `체력 +2`, `정치력 -15`는 반올림해 `정치 -2`로 적용한다.
- 아이템, 엔딩 분기처럼 현재 수동 플레이 모드에 없는 시스템은 우선 로그로 기록하거나 가능한 범위에서 종료/탈락 처리한다.

## 2026-07-07 이동 속도 이벤트 처리

- 이벤트의 이동 속도 관련 효과는 실제 이동 시스템으로 처리하지 않는다.
- 이동 속도 증가는 다음 행동 1회의 능력치 변화 효과를 +1 증가시킨다.
- 이동 속도 감소는 다음 행동 1회의 능력치 변화 효과를 1 감소시킨다.
- 보정은 행동 1회에 적용된 뒤 즉시 소모된다.


## 2026-07-07 수치 모듈 1차 구현

- 기도와 연설의 능력치 변화에 따라 사용자가 어떤 행동을 얼마나 할 수 있는지 확인하는 실시간 수치 모듈을 추가한다.
- 입력 1은 콘클라베 당 턴 수, 턴당 행동 수, X턴당 체력 Y 감소, 기도/연설 성공 및 실패 변화량, 기도/연설 성공률로 구성한다.
- 입력 2는 턴당 기도 횟수, 턴당 연설 횟수, 1일/2일/3일/4일 이후 공작 경건 비용으로 구성한다.
- 턴당 행동 수에서 기도와 연설 횟수를 뺀 남은 행동은 공작 시도로 간주한다.
- 생존률은 시작 체력 10을 기준으로 기도/연설 성공률의 독립 시행 확률분포를 계산한다.
- 일자별 생산량 그래프의 최소/최대/평균은 각각 전부 실패 경로, 전부 성공 경로, 기대값 경로로 계산한다.
- 생존 보장 필요 기도 횟수는 모든 성공/실패 결과 중 최악의 체력 경로에서도 생존 가능한 최소 턴당 기도 횟수로 계산한다. 생존 불가 시 0으로 표시한다.
- 현재 모델은 공작의 효과와 성공률은 계산하지 않고, 경건 비용만 반영한다.

## 2026-07-07 수치 모듈 분포 해석 수정

- 수치 모듈의 `턴당` 해석은 하루 내부의 작은 턴이 아니라, 5~7일 정도의 넉넉한 분석 기간 동안 많은 게임을 돌렸을 때 나타나는 단일 플레이어의 일자별 능력치 변화로 본다.
- 기본 분석 기간은 7일이며, 사용자가 `분석 일수`로 조절할 수 있다.
- `콘클라베 당 턴 수 × 턴당 행동 수`를 하루에 가능한 전체 행동 슬롯으로 계산한다.
- 일당 기도/연설 횟수를 제외한 남은 행동 슬롯은 공작 시도로 간주한다.
- 그래프는 최소/최대 대신 하위 25%, 평균, 상위 25%를 표시한다.
- 생산량 그래프와 현재 능력치 그래프를 분리한다.
- 현재 능력치는 시작 체력/정치/경건 입력값에서 출발해, 일자별 확률분포를 누적해 계산한다.

## 2026-07-07 화면 분리

- 수동 플레이와 수치 분석은 같은 화면에 동시에 표시하지 않고 별도 화면으로 분리한다.
- 상단의 `수동 플레이`, `수치 분석` 버튼으로 화면을 전환한다.
- 수동 플레이 화면에서는 현재 턴 요약을 표시한다.
- 수치 분석 화면에서는 턴 요약을 숨기고 분석 입력, 그래프, 표에 집중한다.

## 2026-07-07 숫자 입력 0값 보존 수정

- 숫자 입력창에 `0`을 넣었을 때 `min` 값으로 자동 변경되지 않도록 한다.
- 빈 값은 최소값으로 보정하되, 명시적으로 입력된 `0`은 유효한 값으로 유지한다.
