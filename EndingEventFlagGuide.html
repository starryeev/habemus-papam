이벤트에서 엔딩 플래그 넣는 방식

이벤트 선택지에서 특정 엔딩으로 바로 보내려면 OnChoiceOption1 또는 OnChoiceOption2 안에서 아래 순서로 호출하면 된다.

기본 호출 순서

EndingContext.CaptureFromCurrentGame();
EndingContext.SetEventTrigger("이벤트ID", 선택지번호);
EndingResult.Set(EndingType.엔딩종류);
Time.timeScale = 1f;
SceneManager.LoadScene("EndingScene");

SceneManager.LoadScene을 쓰려면 이벤트 스크립트 상단에 using UnityEngine.SceneManagement;를 추가해야 한다.

이벤트 스크립트 예시

using UnityEngine;
using UnityEngine.SceneManagement;

public override bool OnChoiceOption1(Cardinal performer)
{
    if (!CanChoiceOption1(performer)) return false;

    EndingContext.CaptureFromCurrentGame();
    EndingContext.SetEventTrigger("E31101", 1);
    EndingResult.Set(EndingType.GreatSage);
    Time.timeScale = 1f;
    SceneManager.LoadScene("EndingScene");

    return true;
}

성전 게임오버 분기

E31201, E31202가 켜진 상태에서 게임오버가 날 때는 아래처럼 이벤트 ID를 넣고 성전 엔딩으로 보내면 된다. 

EndingContext.CaptureFromCurrentGame();
EndingContext.SetEventTrigger("E31201", 1);
EndingResult.Set(EndingType.Crusade);
Time.timeScale = 1f;
SceneManager.LoadScene("EndingScene");

공통 함수로 빼고 싶을 때

여러 이벤트에서 반복될 예정이면 public helper를 하나 만드는 편이 좋다. 현재 DebugEndingFlagController.TriggerEnding(...)은 private이라 이벤트에서 직접 호출할 수 없다. 

public static void LoadEnding(
    EndingType endingType,
    string triggerEventId = "",
    int optionIndex = 0)
{
    EndingContext.CaptureFromCurrentGame();

    if (!string.IsNullOrWhiteSpace(triggerEventId))
    {
        EndingContext.SetEventTrigger(triggerEventId, optionIndex);
    }

    EndingResult.Set(endingType);
    Time.timeScale = 1f;
    SceneManager.LoadScene("EndingScene");
}
